# Responsáveis pelos jogos

Mantenedor geral: **Guilherme Guimarães — @GuimaraesCRM**.

Somente Guilherme pode alterar este cadastro. Cada colaborador só pode alterar a pasta de jogo atribuída ao seu usuário, com a exceção do primeiro PR de um jogo novo descrita em `AGENTS.md`. Nenhum jogo está atribuído neste momento; não interpretar os exemplos como atribuições.

Codenames e Spyfall são ideias iniciais. Um colaborador pode desenvolver um jogo novo em uma nova pasta com o nome do jogo e enviar o primeiro PR sem cadastro prévio. Ele informa o nome do jogo, a pasta, seu nome e usuário GitHub na documentação local e no PR. Guilherme revisa, cadastra manualmente esses dados aqui e aprova o PR antes da integração. O colaborador não altera este arquivo para se cadastrar.

Até essa revisão, o responsável é apenas proposto; conflitos de atribuição são decididos por Guilherme. Para jogos já existentes, o cadastro continua obrigatório. A IA deve confirmar qual jogo será trabalhado quando um colaborador tiver mais de uma atribuição.

Arquivos da raiz, regras de IA, `.github/` e futura infraestrutura compartilhada ficam sob responsabilidade exclusiva de Guilherme.
